## Coin edit

Created with the built-in imagegen tool using the original yellow blob as the edit
target and `public/images/homeshare-blob.png` as a material and lighting reference.

Prompt: Preserve the yellow blob's frontal pose, silhouette, tiny black oval eyes,
two arms holding the stack, centered full-body framing and generous transparent
margins. Refine the stack into four clearly recognizable small thick ivory coins
with subtle milled edges and an embossed simple circular center on the top coin;
no currency text. Soften the body yellow toward warm butter yellow, retaining
dimensional shading. Match the smooth soft matte clay/vinyl material and gentle
studio lighting of the blue reference; do not add a hat or feet. Clean antialiased
silhouette, no stray edge pixels. Genuinely transparent background, no backdrop,
no text, no watermark. Square production UI illustration.
